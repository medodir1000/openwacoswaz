## 1. Product DNA → Chosen Style

**`ui-ux-pro-max` product-type match** (B2B SaaS · WhatsApp automation · workflow/ops tooling):
- Pattern → *Real-Time / Operations* surface (live status, KPI-led, trust-forward).
- Density need → **Data-Dense Dashboard** (12-col grid, KPI cards, compact tables).
- Quality bar → WCAG **AA**, fast, no theatrics.

### Selected style: **Bento Grid × Soft UI Evolution**
A deliberate blend (both were on your priority list, and they're complementary):

| From | We take |
|---|---|
| **Bento Grid / Data-Dense Dashboard** | 12-col grid, modular "tiles", compact spacing, max scannability, KPI-card rows, sortable tables. |
| **Soft UI Evolution** | Soft **multi-layer** shadows (clearer than neumorphism), 10–14px radii, calm 200–300ms motion, **WCAG AA+** contrast hierarchy. |

**Net feel:** an enterprise operations cockpit — dense and trustworthy, but soft-edged and
premium, not flat/clinical and not neon/playful.

**Hard avoids (engine + your brief):** generic AI **purple/pink** gradients · neon ·
heavy neumorphism (low contrast) · dark-mode-by-default · excessive animation · emojis as icons.

## 3. Typography

**Pairing (engine-validated):** display character + dashboard-grade legibility + true numerics.

| Role | Family | Why |
|---|---|---|
| **Display / Headings** | **Plus Jakarta Sans** | engine's top B2B-SaaS pick — modern, geometric, premium. |
| **Body / UI / Data** | **Inter** | the dashboard standard: razor-legible at 12–14px, **tabular numerals** for tables. |
| **Numeric / IDs / code** | **JetBrains Mono** | aligned digits for money, JIDs, references. |

```css
@import url('https://fonts.googleapis.com/css2?family=Plus+Jakarta+Sans:wght@500;600;700;800&family=Inter:wght@400;500;600;700&family=JetBrains+Mono:wght@400;500;600&display=swap');
```

### Type scale (tuned for density — base **14px**)
| Token | Size/Line | Weight | Family | Use |
|---|---|---|---|---|
| `text-display` | 30 / 36 | 700 | Jakarta | page hero numbers |
| `text-h1` | 24 / 32 | 700 | Jakarta | page title |
| `text-h2` | 20 / 28 | 600 | Jakarta | section |
| `text-h3` | 16 / 24 | 600 | Inter | card title |

## 4. Spacing, Grid & Radius

**8-pt base** (4-pt allowed for dense table internals only).
```
--sp-1:4  --sp-2:8  --sp-3:12  --sp-4:16  --sp-5:20  --sp-6:24  --sp-8:32  --sp-10:40  --sp-12:48  --sp-16:64
```
**Bento grid:** `display:grid; grid-template-columns:repeat(12,1fr)`.
- `--bento-gap: 16px` (desktop) · `12px` (dense) · `8px` (ultra-dense tables)
- Tile spans: KPI `col-span-3`, chart `col-span-6/8`, table `col-span-12`, side panel `col-span-4`.
- `--card-pad: 20px` (default) · `16px` (dense) · `12px` (table cell)
- `--sidebar-w: 248px` · `--topbar-h: 60px`

**Radius:** `--r-sm:8 · --r-md:10 (default) · --r-card:14 · --r-modal:20 · --r-pill:999`.
**Breakpoints:** `375 · 768 · 1024 · 1440`. Bento collapses 12→6→1 col.

## 5. Elevation — Soft UI Evolution shadows
Soft, multi-layer, low-opacity. **No** dual-direction neumorphic shadows.
```
--shadow-xs:    0 1px 2px rgba(12,20,24,.05);
--shadow-sm:    0 1px 2px rgba(12,20,24,.06), 0 1px 3px rgba(12,20,24,.04);
--shadow-md:    0 2px 4px rgba(12,20,24,.06), 0 4px 12px rgba(12,20,24,.05);   /* cards/bento tiles */
--shadow-lg:    0 6px 16px rgba(12,20,24,.08), 0 2px 6px rgba(12,20,24,.05);   /* hover-raise, popovers */
--shadow-focus: 0 0 0 3px var(--ring);
```
Hover on a tile/card: `--shadow-md → --shadow-lg` + `translateY(-1px)` over `--motion-base`.

## 6. Motion (strict 150–300ms)
```
--motion-fast:150ms  --motion-base:200ms  --motion-slow:300ms   /* hard ceiling = 300ms */
--ease-standard: cubic-bezier(.2,0,0,1);
--ease-enter:    cubic-bezier(0,0,0,1);
--ease-exit:     cubic-bezier(.3,0,1,1);
```
Animate only `opacity` / `transform` / `color` / `box-shadow` / `background`. **Required** global:
```css
@media (prefers-reduced-motion: reduce){ *,*::before,*::after{ animation-duration:.01ms!important; transition-duration:.01ms!important; } }
```

## 8. Component Primitives (token contract)

**Button**
| Variant | Bg | Text | Hover | Focus |
|---|---|---|---|---|
| Primary | `--brand-600` | #fff | `--brand-700` | `--shadow-focus` |
| Secondary | `--surface` + `1px --border-strong` | `--ink-700` | `--ink-100` | `--shadow-focus` |
| Ghost | transparent | `--ink-600` | `--ink-100` | ring |
| Danger | `--danger-600` | #fff | darken 8% | ring |
Height 36 (md) / 32 (sm) / 40 (lg) · radius `--r-md` · pad `0 14px` · weight 600 · `cursor-pointer` · transition `--motion-fast`.

**Input / Select** — h36, radius `--r-md`, `1px --border`, bg `--surface`; `:focus` → border `--brand-600` + `--shadow-focus`; placeholder `--ink-400`; error → border `--danger-600`.

**Card / Bento tile** — bg `--surface`, `1px --border`, radius `--r-card`, pad `--card-pad`, `--shadow-md`; optional eyebrow + value + delta. Hover-raise only if interactive.

**Table** — sticky header (`--ink-100` bg, `--text-eyebrow`), row-h 44 (36 dense), hover row `--brand-50`, zebra optional `--surface-sunken`, numeric cols right-aligned `text-num`, sortable headers show a Lucide chevron.

**Badge / Pill** (status) — `--r-pill`, pad `2px 10px`, `text-caption` 600, semantic **tint bg + text-on-tint** (e.g. Paid→success, Pending→warning, Failed→danger, Connected→`--signal-green` dot).

**Nav (sidebar)** — bg `--brand-800` or `--surface`; active item: `--brand-600` text + `--brand-50`/overlay bg + 3px left brand bar; `cursor-pointer`; 18px Lucide icon + label.

## 9. Data-Viz / Charts (Recharts)
**Chart-type matrix** (engine guidance — pick by data shape, not taste):
| Data shape | Chart | Notes |
|---|---|---|
| Conversion / pipeline (3–8 stages) | **Funnel / Sankey** | single-color gradient start→end; show **% between stages**; highlight biggest drop. |
| Trend over time (≥4 pts) | **Line / Area** | area fill 20% opacity; differentiate series by **line style**, not color alone. |
| Single KPI + target | **Bullet / Stat card** | compact, delta vs target. |
| Categorical compare | **Bar** | horizontal if labels long. |

**Chart color ramp** (sequential, AA, colorblind-aware): `--brand-700 → --brand-500 → --brand-400 → --info-600 → --warning-600`.
**A11y (mandatory):** explicit numeric/% labels as text · legend always visible · keyboard-traversable · **linear list fallback** (stage/period + value + delta) for screen readers.

## 10. The UX Contract (enforced on every component — non-negotiable)
1. **One clear primary action** per view; never two competing primaries.
2. **`cursor-pointer`** on *every* clickable element (buttons, rows, tabs, icons, cards).
3. **Hover + state transitions 150–300ms**; visible **`:focus-visible`** ring (`--shadow-focus`) on all interactive elements for keyboard nav.
4. **Spacing from tokens only** — rigid 8-pt rhythm; align to the 12-col bento grid.
5. **Contrast ≥ 4.5:1** body / 3:1 large & UI; never convey meaning by **color alone** (pair with icon/label/shape).
6. **`prefers-reduced-motion`** respected globally.
7. **No emojis as icons**; SVG (Lucide) only.
8. **Empty / loading / error** states designed for every async surface (skeletons, not spinners-only).
9. **Numbers** use tabular figures + the app's currency/format helpers (no raw floats).
10. **Responsive** at 375 / 768 / 1024 / 1440; bento reflows, tables scroll, sticky header/footer hold.
11. **RTL-safe** (i18next `ar`): logical properties, mirror chevrons/nav.
12. **Skin via tokens** — a component must theme correctly in light *and* dark with zero hard-coded colors.
